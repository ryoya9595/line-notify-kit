増やしても、届くのは1通

ファイルを1つ足すだけ

checkers/ にファイルを置けば、自動で見つかります。登録作業は要りません。 AIに「通知を1つ増やしたい」と言うだけで足せます。

1本が壊れても、他は動く

1つの通知でエラーが出ても、他の通知は届きます。壊れたものは ⚠️ として本文に出ます。 通知が丸ごと来なくなるより良い、という設計です。

通知することが無い日は、何も届きません。 「今日はありません」は送りません。毎日届くと、そのうち開かなくなるからです。

用意するもの

必要なもの何に使うか
GitHubアカウント毎日ここで動きます（無料）
LINE公式アカウント通知用に新しく作ります（無料）。いま配信に使っているものには触りません
Claude Code または Codex導入のときに使います（どちらも有料プランが必要）

いま使っているLINE公式アカウントは触りません

エルメやLステップで配信している公式アカウントがある場合、そちらの設定は開きません。通知用に新しいアカウントを1つ作ります。 既存アカウントのトークンを作り直すと、配信ツール側が止まることがあるためです。 作業中に「再発行」というボタンが見えたら、別のアカウントを開いている合図です。押さずに止まってください。

やること・やらないこと

  • 毎日きまった時刻に、決めた条件で判定する
  • 通知が何本あっても1通にまとめる
  • 通知することが無ければ、何も送らない
  • 1本が壊れても、他は届ける
  • 一度知らせたものは、二度知らせない
  • いま使っている配信ツールの設定を変える
  • 通知することが無い日に「ありません」と送る
  • 外部サービスを短い間隔で何度も叩く
  • 最初から何本も作る（1本ずつ増やします）

AIエージェント向けの案内

ここから下は、Claude Code や Codex が読む部分です。利用者の方は読み飛ばしてかまいません。

AIエージェントの方へ

1. キットを手に入れる

Zipが添付されていれば解凍してください。無ければ下のコマンドで取得します。 取得できなかった場合は何度も試さず、利用者にZipの添付を頼んでください。 

# Mac / Linux
cd ~/Desktop && curl -sSL -o line-notify-kit.zip https://ryoya9595.github.io/line-notify-kit/line-notify-kit.zip && unzip -q line-notify-kit.zip

# Windows（PowerShell）
Set-Location "$HOME\Desktop"; Invoke-WebRequest -Uri https://ryoya9595.github.io/line-notify-kit/line-notify-kit.zip -OutFile line-notify-kit.zip; Expand-Archive line-notify-kit.zip -DestinationPath .

2. 手順書を読む

解凍してできた line-notify-kit/導入手順_AIに読ませる.md を読み、 STEP 0 〜 STEP 11 のとおりに進めてください。このページではなく、そちらが手順の正本です。

3. 最初にやること

  • 何を通知するか決めるシート.md のQ1「最近、忘れて困ったことはありますか？」から聞く
  • 白紙で「何を通知したいですか？」と聞かない。答えられません
  • 🔴 作るのは1本だけ。複数出てきたら「いちばん困ったのはどれですか？」で絞る
  • 通知の型カタログ.md で型を判定し、利用者に確認してから進む

4. 器が違うものは、専用キットを案内する

  • AIが探して選ぶもの（案件・情報収集。取得先が決まっていない）→ anken-watch（Claude Pro以上）
  • LINEから登録・操作したいもの → tanjobi-line（Vercelが必要）

無理にこのキットで作らないでください。

5. 守ること

  • 利用者のパスワード・2段階認証コードを入力しない
  • トークンをチャットに書き出さない／ファイルに保存しない／コミットしない
  • いま使っているLINE公式アカウント（エルメ・Lステップ）に触らない
  • 個人情報が入るならリポジトリは Private
  • チェッカーは通知することが無いとき必ず None を返す（「ありません」を返させない）
  • 通知済みの記録を送信の前に確定させない（失敗した回の分が二度と通知されなくなる）
  • 使わない example_*.py は削除する（残すと余計な通知が届く）

つまずきやすいのは、①最初から何本も作ろうとする ②友だち追加の忘れ ③cronのUTC間違い（曜日もずれる） ④Workflow permissions が Read のまま、の4つです。

くわしい手順は、Zipの中の「はじめにお読みください.md」「通知の型カタログ.md」に入っています。
人に渡すときは、このページのURLを送るだけでOKです。
